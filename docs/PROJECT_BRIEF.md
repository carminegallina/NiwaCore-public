# Project Brief

## Nome

NiwaCore

## Visione

Costruire un hub locale Raspberry Pi per workflow fotografici/video, storage, review, strumenti droni, luci, dashboard e companion hardware.

## Utenti target

- Proprietario del sistema NIWA.
- Creator/fotografo che usa storage e strumenti locali.
- Valutatori tecnici interessati a Docker, Raspberry, self-hosting e automazioni.

## Ambito

- Pannelli web locali.
- Servizi Docker.
- Gestione storage/media.
- Review foto/video.
- Import da sorgenti esterne.
- Drone tools e shooting tools.
- Firmware ESP32-CAM Companion.

## Fuori ambito iniziale

- Cloud obbligatorio.
- Login/account remoti.
- Pubblicazione di segreti, IP o dati runtime.
- AI finta o simulata come se fosse reale.
